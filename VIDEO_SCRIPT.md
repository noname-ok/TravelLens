## 🎬 **Recording Tips**

### **For Maximum Impact:**

1. **Phone Recording Setup:**
   - Use your real phone running the app
   - Landscape mode works better for showing features
   - Or Use screen recorder (OBS, ScreenFlow, Camtasia)

2. **Voiceover Quality:**
   - Speak clearly & confidently
   - Moderate pace (not too fast)
   - Use a good microphone (even phone earbuds work)
   - Record in a quiet room

3. **B-Roll Suggestions:**
   - Real travel photos (temples, food, signs)
   - App screenshots/recordings
   - Maps/location visuals
   - Happy traveler reactions (optional)

4. **Transitions:**
   - Use simple cuts between scenes
   - Add subtle background music (royalty-free)
   - Text overlays to emphasize key points

5. **Final Checklist:**
   - ✅ Total time: < 5 minutes (4:50 is perfect)
   - ✅ All 3 features demonstrated (Explanation, Translation, Map)
   - ✅ Clear narration
   - ✅ No dead air/delays (lose 1 mark per 30 seconds)
   - ✅ YouTube link ready (unlisted or public)
   - ✅ HD quality (720p minimum)

## 🎥 **Easy Recording Workflow**

```bash
# Option 1: Phone Screen Recording (Easiest)
1. Open app on personal phone
2. Start screen recording (Settings > Screen Recording)
3. Go through each feature step-by-step
4. Stop recording
5. Add voiceover in editing software

# Option 2: Web Browser Recording (Faster)
1. Open app in browser (http://localhost:5173)
2. Use OBS or ScreenFlow to record
3. Record screen + add voiceover afterward

# Option 3: Edit Together
1. Record app demo silently
2. Record voiceover separately in quiet room
3. Sync in video editor (Adobe Premiere, CapCut, etc.)
```
